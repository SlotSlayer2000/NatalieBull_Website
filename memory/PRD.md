# Natalie C Bull Counselling Service - Landing Page PRD

## Original Problem Statement
Build a beautiful landing page for a counsellor (Natalie C Bull) who is starting a counselling service based on her professional profile.

## User Persona
- **Primary User**: Potential clients seeking mental health, AOD counselling, or yoga/mindfulness services in Northern NSW, Australia
- **Secondary User**: Natalie C Bull (admin) managing contact submissions

## Core Requirements (Static)
1. Professional landing page showcasing counselling services
2. Responsive design for all devices
3. Contact form for client inquiries
4. Display of qualifications, experience, and therapeutic approaches
5. Organic, warm, and professional design aesthetic
